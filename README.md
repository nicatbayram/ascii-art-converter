# ASCII Art Converter

A modern and customizable **ASCII Art Converter** built with Python and Tkinter. This tool allows you to convert images into text-based art using various ASCII character sets and themes. It’s perfect for digital artists, programmers, or anyone interested in creative ways to display images.

---

## 🚀 Features

- 🖼️ **Convert Images to ASCII Art**  
  Supports common image formats like `.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`.

- 🔤 **Multiple Character Sets**  
  Choose from a variety of ASCII character sets including Standard, Detailed, Blocks, Shapes, Braille, and more.

- 🎨 **Theme Customization**  
  Switch between Dark, Light, Blue, Green, and Purple themes for a personalized UI experience.

- 🔍 **Adjustable Output**  
  - Set ASCII width and font size
  - Option to invert brightness mapping

- 💾 **Save or Export**  
  Save ASCII output as a plain `.txt` file or an HTML file with styled formatting.

- 📋 **Clipboard Integration**  
  Copy the generated ASCII art directly to your clipboard.

---

## 🖥️ Interface

The GUI is designed with a clean and modern layout using `ttk` styles. Options are neatly grouped into:

- **Settings Panel**: Image selection, width, character set, inversion
- **Preview Area**: Live ASCII output display
- **Controls**: Save, copy, clear, and theme selector

---

## 📦 Requirements

- Python 3.x
- Required libraries:
  - `Pillow`
  - `numpy`

```bash
pip install pillow numpy
```
